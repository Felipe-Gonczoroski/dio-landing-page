# CSS Track Landing Page - DIO Challenge

This project is a **landing page** developed as a **challenge exercise by DIO**.

The goal of this project is to practice and apply **HTML and CSS concepts**, using some of the techniques learned during the course, such as:

- **Flexbox** for responsive layout and element alignment
- **Semantic tags** to improve page structure and accessibility
- Other front-end best practices

> This project serves as practice to enhance skills in building modern and semantic web pages.

# Landing Page Trilha de CSS - Desafio DIO

Este projeto é uma **landing page** desenvolvida como um **exercício desafiado pela DIO**.

O objetivo do projeto é praticar e aplicar conceitos de **HTML e CSS**, utilizando algumas das técnicas aprendidas durante o curso, como:

- **Flexbox** para layout responsivo e alinhamento de elementos
- **Tags semânticas** para melhorar a estrutura e acessibilidade da página
- Outras boas práticas de desenvolvimento front-end

> Este projeto serve como prática para aprimorar habilidades em criação de páginas web modernas e semânticas.
